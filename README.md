# Scheda

Il diario della palestra, pensato per il telefono. Apri il giorno, trovi gli esercizi già
compilati con i pesi dell'ultima volta, correggi quello che cambia e spunti la serie.

Online su **[la-mia-scheda-gym.netlify.app](https://la-mia-scheda-gym.netlify.app)**. Da iPhone:
aprilo in Safari, poi Condividi → Aggiungi alla schermata Home.

- Scheda pronta Push / Pull / Legs, oppure la costruisci tu dal catalogo degli esercizi
- Pesi e ripetizioni per ogni serie, superserie comprese
- Storico degli allenamenti e grafici dei progressi
- Suggerimento quando è ora di aumentare il peso
- Funziona anche senza connessione

Niente account, niente server, niente statistiche: i dati restano sul telefono. Per non
perderli, ogni tanto esporta un backup dalla sezione Scheda.

## Sviluppo

Vite + React + TypeScript.

```bash
npm install
npm run dev      # http://localhost:5180
npm test
npm run build    # dist/
```
